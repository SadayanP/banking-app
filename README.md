# banking-app

Command-line banking application built in Python with OOP and JSON persistence


## What it does
Allows users to create accounts, deposit and withdraw funds, 
and check balances. Account data is saved to a JSON file 
and persists between sessions.

## How to run
1. Make sure Python is installed
2. Run: python banking_app_v3.py

## Built with
- Python
- JSON for data persistence
- Object-oriented design with separate classes for 
  data management, customer actions, and bank transactions

## What I learned
- Separating concerns across multiple classes
- File handling and JSON persistence
- Input validation and error handling
